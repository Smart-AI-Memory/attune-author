# Work with the MCP server

Use this procedure when you need to change how attune-author exposes its capabilities to Claude Code as callable tools — for example, when you're adjusting a tool's input schema, changing a handler's behavior, or tightening path validation.

## Prerequisites

- Access to the project source code
- Familiarity with the files under `src/attune_author/mcp/`

## Steps

1. **Trace the request flow.**
   Read `src/attune_author/mcp/server.py` first. `create_server()` returns
   an `AttuneAuthorMCPServer`, whose `call_tool(tool_name, arguments)`
   method dispatches each incoming request to the matching method on
   `AttuneAuthorHandlers` in `src/attune_author/mcp/handlers.py`. The
   server's `tools` property exposes the schema registry, and `main()`
   is the process entry point.

2. **Identify which layer owns your change.**
   The MCP server splits responsibilities across four modules:
   - Tool input schemas and descriptions live in `get_tools()` in
     `src/attune_author/mcp/tool_schemas.py`. Change this when you're
     adding a parameter or rewording what a tool accepts.
   - Tool behavior lives in the six handler methods on
     `AttuneAuthorHandlers`: `author_init`, `author_status`,
     `author_generate`, `author_maintain`, `author_docs`, and
     `author_lookup`. Change these when you're altering what a tool does.
   - Path safety lives in `validate_file_path()` in
     `src/attune_author/mcp/path_validation.py`. Change this when you're
     adjusting how user-supplied paths are checked.
   - Dispatch and lifecycle live in `AttuneAuthorMCPServer`.

3. **Edit the schema and handler together.**
   If you add or rename a tool parameter, update its entry in
   `get_tools()` and the corresponding handler method in the same
   change. The schema is what Claude Code sees; the handler is what
   runs. A mismatch means the tool advertises inputs it doesn't honor.

4. **Validate any file path a tool accepts.**
   Route user-controlled paths through
   `validate_file_path(path, allowed_dir)`. It raises `ValueError` for
   empty strings, null bytes, system directories, and paths that escape
   the allowed directory — return that error to the caller rather than
   touching the filesystem.

5. **Run the related tests.**
   Target the MCP suite with `pytest -k "mcp"` to catch regressions
   before they reach other developers.

## Verify your change

- Call `create_server()` and confirm the `tools` property lists your
  tool with the schema you expect.
- Call `call_tool()` with representative arguments and confirm the
  handler returns the result you intended — and that invalid paths are
  rejected with a `ValueError` message rather than a crash.
- Confirm the targeted tests pass.
